# HTML Portfolio

An early HTML portfolio exercise using sections, links, a skills table and a contact form. The introduction video file has not been added, and the contact form does not send messages.

[Live demo](https://marvericklnk.github.io/html-portfolio-checkpoint2/)

## Run locally

Download the code and open `index.html` in your browser. You can also open the folder in VS Code and use Live Server.
